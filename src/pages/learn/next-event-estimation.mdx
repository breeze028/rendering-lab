# 下一事件估计

<p className="lead"> 不必等待随机游走恰好找到光源， <br /> 主动检查它是否可见。 </p>

<h2 id="connection">主动连接光源</h2>

在每个非 delta 表面顶点上，主动在发光体上采一个点，求 BSDF 和几何项，并追踪阴影连接。连接被遮挡时，贡献为零。这就是下一事件估计（Next Event Estimation，NEE）：在继续随机游走的同时，增加一个直接光照估计。

对采样的入射方向 $\omega_i$，直接光照估计为：

$$
\widehat L_d=\frac{f_r(\omega_o,\omega_i)L_e(y,-\omega_i)V(x,y)|n_x\cdot\omega_i|}{p_\omega(\omega_i)}.
$$

其中 $V$ 表示可见性，采样概率也必须包含发光体选择概率。本 runtime 先在发光三角形之间均匀选择，再在所选三角形上均匀采样面积。因此，拆成两个三角形的正方形光源对应两个候选项，并非按 Parser 中的光源实体均匀选择。

<h2 id="measure">面积与立体角是不同的测度</h2>

面积 PDF 不能直接与 BSDF 的立体角 PDF 比较。令 $r=\|y-x\|$，使用以下变量变换：

$$
p_\omega(\omega_i)=p_A(y)\,\frac{r^2}{|n_y\cdot(-\omega_i)|}.
$$

对于 Cornell 的漫反射面光源，本 runtime 使用 $p_A=1/(N_\mathrm{tri}A_\mathrm{tri})$。阴影射线采用偏移后的起点，并在抵达发光体前终止，以避免自相交。背向的单面发光体贡献为零。

<h2 id="accounting">避免重复计算同一类光照路径</h2>

继续延伸的 BSDF 随机路径也可能命中同一个发光体。如果在完整的 NEE 贡献之外，再累加完整的发光体命中贡献，就会将直接光照计算两次。两种有效做法是：仅使用 NEE 时抑制非 delta 路径的发光体命中，或者用 MIS 对两种估计加权。相机直接可见的发光体与 delta 链需要单独处理，因为普通连续光源采样无法构造这些路径。

Cornell 实验提供了这三种模式。[进入 MIS 课程并运行实验 →](../../#renderer)
